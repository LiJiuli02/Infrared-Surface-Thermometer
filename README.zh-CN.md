# 红外表面温度计

[English](README.md) · [搭建指南](docs/GETTING_STARTED.md) · [系统架构](docs/ARCHITECTURE.md) · [验证与限制](docs/VALIDATION.md) · [项目展示](docs/PORTFOLIO.md)

本仓库存放一个基于 MSP430 的非接触式表面温度测量课程项目固件，结合双通道模拟采集、传感器本体温度补偿、五位数码管显示，以及基于 DS1302 实时时钟（RTC）的带时间戳串口输出。

转换代码将传感器标注为 **SI-111**。公式依赖原始模拟前端和标定常数；仓库尚未包含可用于确定测温精度的原理图或标定报告。

**状态：** 包含源码及历史 IAR 构建产物，但没有完整 IDE 工程或可复现的全新构建配置。本次文档更新未重新验证实物运行。

## 源码中的功能

- ADC12 双通道重复转换及十次采样平均。
- 电阻到传感器本体温度的换算，以及放大/抬升信号到目标温度的计算。
- 中断驱动的数码管动态扫描。
- DS1302 寄存器读写与日期时间格式化。
- 假设 8 MHz 时钟下的标称 9600 波特率串口报告。

## 项目概览

| 项目 | 依据 |
| --- | --- |
| MCU 系列 | 使用 MSP430x24x 头文件；历史构建元数据标注 MSP430F249 |
| 历史环境 | 历史路径为 IAR Embedded Workbench 6.4；编译器元数据记录 V5.50.1.20465 |
| 模拟输入 | P6.0/A0 与 P6.1/A1 |
| 显示接口 | P4 数据总线，P5.5 段锁存，P5.6 位锁存 |
| RTC | DS1302：P2.7 复位/使能，P2.5 时钟，P2.6 数据 |
| 串口 | P3.4 TX，P3.5 RX；标称 9600、8N1 |
| 报告循环 | 两次 `delay_ms(1000)`，实际周期还受中断执行影响 |
